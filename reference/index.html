EasyWhisperUI

Cross-platform desktop app that makes local Whisper (whisper.cpp) transcription beginner-friendly with GPU acceleration on Windows and macOS. Migrated the UI to Electron (React + TypeScript) with a secure IPC bridge for privileged operations. Automated Windows setup installs/validates dependencies and stages whisper.cpp for Vulkan acceleration (Intel/AMD/NVIDIA). Supports queue-based batch transcription and live transcription (whisper-stream) with streamed output/events back to the UI. Integrates FFmpeg for media preprocessing and automatic Whisper model downloads.

Auto 60hz C++

Lightweight C++ app that automatically switches between 60Hz and 120Hz (or custom) refresh rates based on active applications. Built using WinAPI and PSAPI for fullscreen detection, with a modern Qt interface, custom refresh values, and startup integration. Runs silently with zero CPU usage, designed for efficiency and battery savings.

Machine Learning with Python

A PyTorch-based reinforcement learning project where an AI agent learns to play Snake by interacting with the game environment. The agent uses a neural network (Linear_QNet) to predict moves, stores experiences in replay memory, and balances exploration with exploitation as it trains. After each game, the agent restarts automatically and continuously improves its score by learning from both short- and long-term memory. Training progress and scores are visualized, making the learning process transparent.
